- 已定位到与“流式”相关的接口：

- 原默认阈值为 `200ms`，内容整理流式过程中多次数据库读写较容易触发慢 SQL Warn 输出。
- 本次仅调整慢 SQL 打印阈值，不删除数据库 AI 调用日志，不改变接口响应和业务流程。
