# 改动方案提示词

> 用途：让 AI 输出标准化的"改动方案"，等待用户评审。

---

## 复制下面这段使用

```
请按 @ai_workspace/method/templates/改动方案模板.md 输出本次改动方案，
覆盖：影响范围 / 涉及文件 / 接口变化 / 表结构变化 / 配置变化 / 风险点 / 实施顺序 / 验证方式。

在我确认前不要写任何业务代码。
```

---

## 检查清单（AI 自检）

输出方案前自查：

- [ ] 已读 `project/项目介绍.md`，了解项目端与代码路径
- [ ] 影响范围已识别到所有相关端
- [ ] 涉及文件清单完整（新增/修改/删除分开）
- [ ] 接口变化标注向后兼容性
- [ ] 表结构变化含 DDL 草稿
- [ ] 列出至少 1 个风险点（即使是"无明显风险"也要说明依据）
- [ ] 实施顺序符合"基础→上层"的依赖关系
- [ ] 没有改任何已有方法签名（如必须改，单独说明并提风险）
