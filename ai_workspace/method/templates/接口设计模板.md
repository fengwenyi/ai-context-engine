## 3. 接口详情

### A-01 创建 xxx
- **方法 & 路径**：`POST /api/v1/xxx`
- **鉴权**：需要登录
- **请求体**：
  ```json
  {
    "name": "string",
    "count": 0
  }
  ```
- **响应**：
  ```json
  {
    "code": 0,
    "data": { "id": 123 }
  }
  ```
- **业务规则**：
  - 名称唯一
  - count 不能小于 0
- **错误码**：
  - 4001 名称已存在
  - 4002 参数非法
- **依赖**：xxx 服务
