## 公共约定

### 响应结构
```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```
- `code = 0` 表示成功，其它为错误码
- 错误时 `data` 可为 null

### 分页参数
- `page`：从 1 开始
- `page_size`：默认 20，最大 100

### 时间格式
- 统一使用 ISO 8601（如 `2025-05-24T10:00:00+08:00`）

## 接口列表

### 1. 创建 xxx
- **方法**：`POST /api/v1/xxx`
- **鉴权**：需要

**请求**：
```json
{
  "name": "示例",
  "count": 10
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| name | string | 是 | 名称，1-50 字 |
| count | int | 是 | 数量，>=0 |

**响应**：
```json
{
  "code": 0,
  "message": "ok",
  "data": { "id": 123 }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| data.id | int | 新建记录 ID |

**错误码**：
| code | 含义 |
|---|---|
| 4001 | 名称已存在 |
| 4002 | 参数非法 |

**示例**：
```bash
curl -X POST https://api.example.com/api/v1/xxx \
  -H "Authorization: Bearer xxx" \
  -d '{"name":"示例","count":10}'
```
