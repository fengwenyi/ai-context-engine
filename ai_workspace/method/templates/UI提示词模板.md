# UI 提示词

> 用途：用文字描述页面，喂给专业 UI AI 工具（Figma AI / v0 / Galileo 等）生成 UI 稿。
> 一个页面一份文件，命名 `{页面名}.md`。

---

## 页面：{页面名}

### 1. 页面目标
- 用户来这个页面想做什么
- 页面在整体流程中的位置

### 2. 端 & 形态
- 端：Web 管理端 / 用户 Web / 小程序 / App
- 形态：列表页 / 详情页 / 表单 / 仪表盘 / 弹窗

### 3. 整体布局
- 区域划分（顶部导航、侧边栏、主内容区、底部）
- 主内容区的栅格/分块

### 4. 组件清单
| 区域 | 组件 | 说明 |
|---|---|---|
| 顶栏 | 标题 + 操作按钮 | 「新建」「导出」 |
| 主区 | 表格 | 列：xxx, xxx, 操作 |
| 主区 | 分页 | 默认 20/页 |
| ... | ... | ... |

### 5. 交互行为
- 点击「新建」→ 打开新建弹窗
- 点击行「编辑」→ 跳转编辑页
- 选中多行 → 顶部出现批量操作条
- ...

### 6. 状态展示
- 空状态：xxx
- 加载中：骨架屏 / loading
- 错误：错误提示 + 重试

### 7. 视觉风格
- 配色：主色 #xxx，辅色 #xxx
- 字体：xxx
- 圆角、阴影、密度等基调

### 8. 响应式（如适用）
- 断点行为

### 9. 参考
- 类似产品的截图 / 链接（如有）
