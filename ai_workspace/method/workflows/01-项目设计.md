# 场景 1：项目设计（从 0 到 1）

> 触发：还没有项目，AI 辅助完成产品/技术从 0 到 1 的设计。
> 目标：产出"能据此搭建工程骨架"的完整设计产物。

---

## 流程总览

```
需求/想法
  ├─ 1. 产品业务流程梳理
  ├─ 2. 产品形态 / 闭环 / 运营
  ├─ 3. 技术选型（各端）
  ├─ 4. 系统架构设计
  ├─ 5. 初版数据库设计
  └─ 6. 项目骨架搭建（按选型）
```

每一步都是先沟通对齐→出文档→用户确认→进入下一步。

---

## 步骤详解

### 1. 产品业务流程梳理
- **输入**：用户的业务想法、目标用户、核心场景
- **AI 动作**：先问清楚（用户群体、核心动作、价值链路、关键约束），再画业务流程
- **产物**：`project/designs/产品业务流程.md`
- **模板**：[PRD 模板](../templates/PRD模板.md)

### 2. 产品形态 / 闭环 / 运营
- **输入**：业务流程
- **AI 动作**：明确产品形态（App / 小程序 / Web / 管理端的组合）、用户闭环、运营动作（增长/活跃/留存）
- **产物**：`project/designs/产品设计.md`

### 3. 技术选型
- **输入**：产品形态、性能/成本约束、团队偏好
- **AI 动作**：分端给方案（语言 / 框架 / 数据库 / 中间件 / 部署），列优劣，等用户拍板
- **产物**：`project/designs/技术选型.md`

### 4. 系统架构设计
- **输入**：产品形态 + 技术选型
- **AI 动作**：画整体架构图（端、服务、数据流、外部依赖），说明分层与边界
- **产物**：`project/designs/系统架构.md`
- **模板**：[系统设计模板](../templates/系统设计模板.md)

### 5. 初版数据库设计
- **输入**：核心业务实体
- **AI 动作**：列核心实体、关系、关键字段；输出 ER 草图与建表 SQL（仅核心表）
- **产物**：`project/designs/数据库设计.md` + `project/designs/initial.sql`
- **模板**：[数据库设计模板](../templates/数据库设计模板.md)
- **规范**：[数据库设计规范](../specs/数据库设计规范.md)

### 6. 项目骨架搭建
- **输入**：技术选型 + 系统架构
- **AI 动作**：按各端建仓库/目录结构，初始化依赖与基础配置
- **产物**：可运行的空工程；同步更新 `project/项目介绍.md`（端清单、代码路径、技术栈）

---

- 6 项产物齐全且经用户确认
- `project/项目介绍.md` 已填写完整
- 项目骨架可启动（最小可运行状态）
